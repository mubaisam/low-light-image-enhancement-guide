# Contributing

欢迎补充弱光图像增强相关论文、数据集、代码和评测工具。

提交 PR 前请确认：

1. 论文信息准确（标题、作者、会议/期刊、年份）；
2. 链接可以正常访问；
3. 新增论文按年份倒序排列（新论文在上）；
4. 不直接上传受版权保护的论文 PDF 或数据集文件；
5. 如补充代码，请注明依赖和运行方式。

对于较大的改动（如新增章节或重构结构），建议先开 issue 讨论。

---

Contributions to this low-light image enhancement guide are welcome.

Before submitting a pull request, please ensure:

1. Paper information is accurate (title, authors, venue, year);
2. All links are accessible;
3. New papers are sorted in reverse chronological order;
4. No copyrighted PDFs or datasets are uploaded directly;
5. Any added code includes dependency and usage instructions.

For major changes, please open an issue first to discuss.
